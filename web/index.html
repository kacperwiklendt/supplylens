Sample replay

Three synthetic scenarios with fixed, hand-reviewed findings. Changing the selected scenario changes the example; it does not call a model.

Live AI

Run the Python app and configure an OpenAI API key on the server. Your text is sent to OpenAI for analysis. The offline preview cannot analyze custom documents.

Evidence is a starting point

Python checks whether each quoted passage exists in its source. That check does not prove the classification is correct or that all requirements were covered. A matching supplier claim is not independent verification.

Your work stays in this session

No automatic document history. Notes and review checks are kept in memory; refreshing clears them. Export to keep a copy. Exports include source documents.
